# Deny IP Toolkit 0.2.0

This release adds hardened source ingestion, versioned source manifests,
configurable overlap handling, saved run reports, coverage-loss safeguards,
and plain-text, CSV, JSON, ipset, nftables and conservative Synology Auto Block
exports. The default output remains plain text.

No licensed, private or donor-only IP list is included. The Synology export is
an output format for individual IPv4 addresses; it does not download a
password-protected Synology share.

See [installation and verification](https://github.com/SanderHill/deny-ip-toolkit/blob/v0.2.0/docs/RELEASES.md)
and the [full changelog](https://github.com/SanderHill/deny-ip-toolkit/blob/v0.2.0/CHANGELOG.md).

The source archive is built from the tagged commit. The container image supports
Linux amd64 and arm64; use its published digest for the strongest deployment pin.
